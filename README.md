# Melb Nights Out

A full-stack web app concept for planning Melbourne nights out based on happy hours, food deals, venue times and public transport routes.

## Planned Features
- Search happy hours by suburb
- View food and drink deals
- Plan a route between venues
- Prioritise tram/train-friendly locations
- Save favourite venues
- Interactive Melbourne map

## Tech Stack
- React
- JavaScript
- Tailwind CSS
- Future: PostgreSQL, backend API, PTV API, Google Maps API
